# 数据格式说明

## 数值任务

数值数据使用 UTF-8 纯文本 `.txt` 文件，每行代表一个样本，字段之间用空格分隔。空行会被忽略，但每行期望字段之后不能有额外内容。

### 训练和测试

如果模型有 `n` 个输入特征，每行必须包含 `n` 个数值特征和一个目标：

```text
x1 x2 ... xn target
```

回归目标是数值：

```text
0.0 0.0 1.0
1.0 2.0 8.0
```

分类目标是不含空格的字符串：

```text
0.1 0.2 low
0.9 0.8 high
```

分类训练至少需要两个类别，且每个类别至少两个样本，以便生成分层训练集和验证集。测试文件中的分类标签必须在训练时出现过。

### 推理

推理文件只包含 `n` 个特征，不包含目标：

```text
x1 x2 ... xn
```

训练时计算的归一化参数会与模型一起保存，测试和推理会自动重用。

## 图像任务

支持 `.jpg`、`.jpeg`、`.png`、`.bmp`、`.tif` 和 `.tiff`。

### 训练和测试

数据集根目录下每个子目录代表一个类别，子目录名即标签：

```text
dataset/
|-- cats/
|   |-- cat-01.jpg
|   `-- cat-02.jpg
`-- dogs/
    |-- dog-01.jpg
    `-- dog-02.jpg
```

类别目录和图片文件按名称排序，以保持标签编码稳定。空类别目录会被忽略并输出警告。分类训练同样要求每类至少两张有效图片。

### 推理

将待预测图片直接放在同一个目录中，不需要类别子目录：

```text
inference/
|-- image-01.jpg
`-- image-02.png
```

图片会按文件名排序并按批次解码。如果扩展名受支持但文件已损坏，程序会报告该文件的完整路径。

## 本地模型数据

训练产物保存在项目运行目录下的 `data/`，包括模型权重、归一化参数、标签映射和模型元数据。整个目录已被 Git 忽略，不会推送到公开仓库。
